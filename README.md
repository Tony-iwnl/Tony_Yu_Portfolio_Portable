# 余思洋 Tony Yu · 可移植作品集

## 打开与部署
解压后打开根目录 index.html 即可浏览。建议上传整个目录到任意静态 HTTP/HTTPS 网站空间，入口为 index.html；不需要安装依赖或执行构建。部署到子目录也可使用，保留 assets/ 和相对路径即可。

## 内容
保留当前网站的 HTML、CSS、JavaScript、8 张 WebP 图片和 1 个 MP4 背景视频。页面标题、描述、主题颜色、内嵌 SVG 图标都保留在 index.html；纹理内嵌在 CSS 中。没有独立数据库或 JSON 内容源，作品信息和联系方式在 HTML 中。
documents/Tony_Yu_3D_Portfolio.pdf 为附带的 9 页作品集文档，网站正常运行不依赖它。

## 字体
原站仅指定系统字体回退：Inter、Noto Sans SC、Microsoft YaHei、sans-serif；没有下载字体、字体文件或字体 CDN。为保持当前实现，不打包系统商业字体。不同设备可能使用不同的回退字体，排版会有轻微差异。

## 保留的交互
背景视频静音循环、滚动显现、海报轻微抬起、6 秒彩色渐变和三组带阻尼的线框/渲染拖动对比均在浏览器中运行。浏览器的自动播放和省电设置可能暂停视频。邮箱链接打开访客自己的邮件软件，不会在服务器上发送或保存邮件。

## 不属于静态导出的功能
该站没有业务服务器、数据库、远程对象存储、上传接口、会员系统或 API 依赖。Sites 的原域名、SSL 证书、CDN、发布历史、平台权限/登录网关以及托管配置不会随 ZIP 转移；新托管方负责域名、HTTPS 与访问权限。本包不需要 GPT 登录，也不包含认证逻辑。
PDF 中指向原公开网站的 HTTPS 链接保留；这只是可点击链接，不是运行依赖。迁移后可按需更新文档里的链接。

## 隐私与清单
只导出白名单内的公开网站资源和作品集 PDF。不包含 Git 历史、.openai、环境文件、密钥、令牌、对话、提示词、构建脚本、客户记录或本机绝对路径。保留已公开的作者姓名、专业、广州和邮箱，属于作品集正文。
FILELIST.txt 列出包内每个文件。EXPORT_REPORT.json 记录引用检查、SHA-256 校验值与验证结果。
